# Changelog

All notable changes to L-ai-SERctrl. Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
newest first.

## 1.2.1 - 2026-10-25

### Changed
- Rebrand to **L-ai-SERctrl**: new name in window title, dialogs, logs and all 20 language files.
- Technical rename: binary `laiserctrl`, packages `L-ai-SERctrl-<version>-...`, desktop entry and AppStream id
  `io.github.mechaot.laiserctrl`.
- Config folder is now `L-ai-SERctrl`; an existing `LaserGRBL` config folder is copied over automatically once
  on first start (the old folder stays untouched).
- New original splash screen and app icon.
- New "License & Credits" dialog crediting LaserGRBL and its author Diego Settimi, with the GPL text.
- Parameters dock: group boxes span the full width.

### Removed
- Donate entry/button and the online-links section (Help online, FAQ, Facebook community) of the help menu.

### Legal
- GPLv3 fork notices: `LICENSE.md` names Andreas Pösch (L-ai-SERctrl) and Diego Settimi with the LaserGRBL
  contributors (LaserGRBL), carries the modification notice (GPLv3 section 5a) and states that the project is
  independent and not endorsed by LaserGRBL. The LaserGRBL license text is unchanged.
- New `NOTICE.md`: authors, LaserGRBL contributors and translators (README credits and git history), and
  third-party code and assets with their licenses (GRBL-Plotter, Potrace, Clipper, Cyotek dithering, Hershey
  fonts, Material Design Icons, ...).
- SPDX license and copyright headers in every Rust, Python and shell source file; `tools/check_headers.py`
  checks them in CI.
- Licenses of the Rust dependencies: `THIRD_PARTY_RUST.md` (generated by `tools/gen_third_party.py`) and
  `THIRD_PARTY_LICENSES.txt` in the release packages.
- Release packages contain `LICENSE.md`, `NOTICE.md`, `CHANGELOG.md` and `THIRD_PARTY_LICENSES.txt`; the
  complete source ships next to them as `L-ai-SERctrl-<version>-source.tar.gz` (GPLv3 section 6).
- "License & Credits" dialog: both copyright holders, the legal notice with the no-warranty statement, the
  independence statement, the third-party credits and the full NOTICE text.
- Authors in the package metadata, AppStream developer name and README updated.

### Fixed
- Flaky dock tests (process-wide firmware setting leaked between tests).

Commits: 5882687

## 1.2.0 - 2026-10-25

### Added
- Hatch fill for closed shapes per layer: line distance, angle, optional cross hatch.
- "Fill per shape" ordering option for hatch fill.
- Layer presets store the fill settings.

Commits: 1678e92, 141e886

## 1.1.3 - 2026-10-25

### Changed
- Named layer presets replace the material database: save the layer settings under a name, pick a preset,
  delete presets in the list. Stored as a JSON file in the config folder. The raster import dialog can pick a
  preset too.

Commits: 2b2bba1

## 1.1.2 - 2026-10-25

### Changed
- Parameters dock: Apply button removed, G-code regenerates automatically after each edit.

### Fixed
- Edits made during a running generation were lost.

Commits: 6457821

## 1.1.1 - 2026-10-20

### Added
- GitLab CI: clippy, tests, Linux AppImage, Windows and macOS packages.

### Removed
- Telemetry and the update check.

Commits: 0b005d9, c60bab4, 01ed282

## 1.1.0 - 2026-10-20

### Added
- Parameters dock replaces the modal SVG import dialog.
- Per-layer SVG settings: layer picker, enable, passes, speed, power, laser mode, colour filter, sync,
  per-file storage and preview highlight.

Commits: bb85589, e20c84e

## 1.0.0 - 2026-10-20

First release. The changelog starts here.

### Added
- **Rust port of LaserGRBL 7.14.1** by Diego Settimi and the LaserGRBL contributors (C#/WinForms, Windows
  only) to Rust/egui, running on Linux, Windows and macOS. G-code generation is checked against the original with golden tests.
- AppImage builder.
- Source and architecture documents.

Credit: L-ai-SERctrl is based on [LaserGRBL](https://github.com/arkypita/LaserGRBL) by Diego Settimi and
the LaserGRBL contributors.

Commits: 47cd1b3, 1bff3d3, f38b1fa
