# Changelog

All notable changes to L-ai-SERcraft. Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
newest first.

## Unreleased

### Added
- Raster images (jpg, jpeg, bmp, png, gif) open straight into the Parameters dock instead of the modal import dialog.
  The dock engraves line to line and regenerates the G-code after every edit: brightness histogram with draggable
  start / stop markers (brightness → S-MAX / S-MIN, inverted maps allowed, brightness outside the range is not
  burned), lower-left corner and size in mm (upper right is calculated; an aspect lock between width and height,
  closed at every start; aspect ratios shown), direction, quality, engraving speed, laser mode and S-MIN / S-MAX.
  Values are remembered per file.
- Button "Classic import dialog…" in the image dock opens the old dialog (dithering, vectorize, centerline). `.lps`
  project entries still use the classic dialog.
- `LayerPresets.json` is created with the example preset on first start (also after a broken file is moved to `.bak`).

### Changed
- Crash dialog and issue detector point to https://github.com/mechaot/L-ai-SERcraft/issues instead of the LaserGRBL tracker.
- Longer and Ortur menus keep only the WiFi setup entry: the vendor links (support, YouTube, manuals, firmware) were LaserGRBL partner pages and are gone.
- "Help online" opens the manual in this repository. The info buttons still open the LaserGRBL documentation, see README.
- Settings texts no longer say that LaserGRBL does something; other languages fall back to English for them.
- Dev: all tests now write only to temp folders (`lg_base::paths::isolate_for_tests`), never to `~/.config/L-ai-SERcraft`. `tools/check_test_isolation.py` runs every test alone with a scratch HOME/XDG and fails on any file left behind; CI runs it on Linux.

### Removed
- Unused texts of the removed donate, community, auto-update and Telegram features from all language files.

## 1.3.0 - 2026-10-26

### Changed
- Renamed from L-ai-SERctrl to L-ai-SERcraft: window title, UI texts in all languages, splash screen, docs, packages (binary `laisercraft`, app id `io.github.mechaot.laisercraft`, package files `L-ai-SERcraft-<version>-...`).
- Config folder is now `L-ai-SERcraft`; on first start an existing `L-ai-SERctrl` folder is copied over (else the old `LaserGRBL` folder, as before).

### Added
- GitHub Actions CI (`.github/workflows/ci.yml`): lint, tests, AppImage, Windows and macOS packages, source tarball; master builds go to the rolling `nightly` pre-release, `v*` tags make a release.
- User manual `docs/MANUAL.md`: multi-layer SVG from Inkscape (cut and fill layer) with screenshots.

Commits: c5bb65a, ada09a4

## 1.2.1 - 2026-10-25

### Changed
- Rebrand to **L-ai-SERctrl**: new name in window title, dialogs, logs and all 20 language files.
- Technical rename: binary `laiserctrl`, packages `L-ai-SERctrl-<version>-...`, desktop entry and AppStream id
  `io.github.mechaot.laiserctrl`.
- Config folder is now `L-ai-SERctrl`; an existing `LaserGRBL` config folder is copied over automatically once
  on first start (the old folder stays untouched).
- New original splash screen and app icon.
- New "License & Credits" dialog crediting LaserGRBL and its author Diego Settimi, with the GPL text.
- Parameters dock: group boxes span the full width.

### Removed
- Donate entry/button and the online-links section (Help online, FAQ, Facebook community) of the help menu.

### Legal
- GPLv3 fork notices: `LICENSE.md` names Andreas Pösch (L-ai-SERctrl) and Diego Settimi with the LaserGRBL
  contributors (LaserGRBL), carries the modification notice (GPLv3 section 5a) and states that the project is
  independent and not endorsed by LaserGRBL. The LaserGRBL license text is unchanged.
- New `NOTICE.md`: authors, LaserGRBL contributors and translators (README credits and git history), and
  third-party code and assets with their licenses (GRBL-Plotter, Potrace, Clipper, Cyotek dithering, Hershey
  fonts, Material Design Icons, ...).
- SPDX license and copyright headers in every Rust, Python and shell source file; `tools/check_headers.py`
  checks them in CI.
- Licenses of the Rust dependencies: `THIRD_PARTY_RUST.md` (generated by `tools/gen_third_party.py`) and
  `THIRD_PARTY_LICENSES.txt` in the release packages.
- Release packages contain `LICENSE.md`, `NOTICE.md`, `CHANGELOG.md` and `THIRD_PARTY_LICENSES.txt`; the
  complete source ships next to them as `L-ai-SERctrl-<version>-source.tar.gz` (GPLv3 section 6).
- "License & Credits" dialog: both copyright holders, the legal notice with the no-warranty statement, the
  independence statement, the third-party credits and the full NOTICE text.
- Authors in the package metadata, AppStream developer name and README updated.

### Fixed
- Flaky dock tests (process-wide firmware setting leaked between tests).
