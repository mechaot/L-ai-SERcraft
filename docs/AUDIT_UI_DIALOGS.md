## Fonts
`RichText::strong()` renders regular in this build; every WinForms-bold caption in the forms now uses `crate::ui::fonts::bold` (form titles, Settings notification/Telegram captions, RunFromPosition, LegalDisclaimer, PSHelper/PSEditor).

## EmulatorUI placement vs `main_form::center_emulator`
Both set the position: `emulator_ui.rs` uses `pivot(CENTER_CENTER).default_pos(content_rect centre)` (only used when egui has no remembered state), `main_form.rs` writes the area state at open time using `monitor_size`. The main_form value wins and is computed from the monitor, while egui window coordinates are relative to the app viewport, so with a window smaller than the monitor the emulator can land off-centre. Recommendation: remove `center_emulator` and its `emulator_was_visible` field from main_form.rs and rely on emulator_ui.rs (a re-shown window keeps its last position; C# re-centres every time, minor).

* ui/widgets `data_grid` (owned by P4-3) uses `Column::initial`; fine in a vertical layout but doubles when put in a horizontal one. Callers must avoid that.
* Esc handling of egui modals cannot distinguish Esc from the close box.
