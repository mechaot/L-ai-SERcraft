# Non-UI API reference for UI work packages

Authoritative source is the code (`crates/*/src`); this is a map. All crates re-export at their root.

## `lasergrbl_core` (crates/core) — engine
* `GrblCore::new(fw: lg_gcode::config::Firmware, events: Sender<CoreEvent>) -> Arc<GrblCore>` (firmware from setting "Firmware Type", fixed per process); `firmware()`, `configure(WrapperType, &ComConfig)`, `wrapper_type()`, `open_com() -> Result<(), String>` (Err text → connect error box, title `Strings.BoxConnectErrorTitle`), `close_com(user)`, `exiting()`, `is_connected()`, `hk_connect()`, `hk_disconnect_needs_confirmation()`, `hk_disconnect()`.
* `CoreEvent`: `IssueDetected(DetectedIssue)`, `MachineStatusChanged`, `FileLoading{elapsed_ms, filename}`, `FileLoaded{elapsed_ms, filename}`, `OverrideChanged`, `LoopCountChanged(Decimal)`, `JogStateChanged(bool)`, `AutoSizeDrawing`, `ZoomInDrawing`, `ZoomOutDrawing`, `ProgramEnded`. Drain every frame.
* Status: `machine_status`, `in_program`, `program_target/sent/executed`, `program_time`, `program_global_time`, `projected_time`, `machine_position`, `work_position`, `working_offset`, `executed`, `sent_command(index, count) -> Vec<SentRow>` (`SentRow: lg_gcode::GrblRow`), `used_buffer/free_buffer/buffer_size/grbl_block/grbl_buffer`, `override_g1/g0/s`, `t_override_*` + `set_t_override_*`, `current_f/current_s`, `loop_count/set_loop_count`, `detected_ip`, `failed_connection_count`, `grbl_version/set_grbl_version`, `is_ortur_board/is_longer_board`, `GrblCore::configuration()/set_configuration()`, `validate_config(parid)`, `usage_counters()/update_usage_counters(|c|..)`, `jog_speed/jog_step` (+setters), `suspend_hk`, `continuous_jog_enabled`, `current_streaming_mode`, `ui_show_grbl_config`, `ui_show_unlock_buttons`, `queue_empty`, `view_options()` (RetainedSettings show_laser_off_movements, show_executed_commands, show_performance_diagnostic, show_bounding_box, cross_cursor, preview_line_size, auto_size_on_drawing).
* Can/Support flags: `support_rto, support_true_jogging, support_csv, support_override, support_laser_mode, support_auto_cooling, auto_cooling, auto_cooling_on/off, has_program, can_reopen_file, can_load_new_file, can_send_file, can_abort_program, can_import_export, can_reset_grbl, can_send_manual_command, can_do_homing, can_do_zeroing, can_unlock, can_feed_hold, can_resume_hold, can_read_write_config, jog_enabled`.
* Immediate/queue: `cycle_start_resume(auto)`, `feed_hold(cooling)`, `safety_door()`, `grbl_reset()`, `send_immediate(b, mute)`, `manage_overrides()`, `hot_key_override(OverrideAction)`, `unlock_from_buffer_stuck(auto)`, `is_buffer_stuck()`, `enqueue_command(&GrblCommand)`, `send_homing_command`, `send_unlock_command`, `grbl_homing`, `grbl_unlock`, `set_new_zero`, `execute_custom_code(&str)`, `evaluate_expression(&str)`, `add_message(GrblMessage)`.
* Jog: `jog_to_position(PointF, speed)`, `jog_to_position_fast(PointF, fast)`, `continuous_jog_to_position`, `jog_to_direction(dir, speed, step)`, `jog_to_direction_fast(dir, fast)`, `jog_to_direction_step_fast(dir, fast, step)`, `continuous_jog_to_direction`, `jog_abort`, `continuous_jog_abort`, `rise_jog_state_change(bool)`.
* Programs/files: `run_would_ask_resume() -> bool` (to keep C# order of SafetyCountdown vs ResumeJobForm), `run_program() -> RunDecision::{Started, AskResume(ResumeInfo{executed,sent,target,last_issue,homing_enabled,suggest_homing,suggest_setwco,last_known_wco}), NotAllowed}`, `run_program_from_start_user(homing)`, `run_from_position_info() -> Option<RunFromPositionInfo{line_count, homing_enabled}>`, `continue_program(position, homing, setwco)`, `abort_program()`, `loaded_file() -> Arc<RwLock<GrblFile>>`, `open_file(&Path, append) -> OpenFileOutcome::{GCodeLoading, Raster(path), Svg(path), Project(path), Unsupported, Busy}` (sets "Core.LastOpenFile", counts usage), `reopen_file()`, `save_program(path, header, footer, between, cycles, lf)`, `auto_size_drawing()`, `zoom_in_drawing()`, `zoom_out_drawing()`, `IMAGE_EXTENSIONS/GCODE_EXTENSIONS/PROJECT_FILE_EXTENSIONS`.
* Config (blocking — run off the UI thread): `refresh_config(RefreshCause)`, `refresh_machine_info()`, `write_config(&[GrblConfParam]) -> Result<(), CoreError::WriteConfig{message, errors}>`, `write_wifi_config(ssid, pwd)`.
* Enums: `ThreadingMode`, `MacStatus`, `DetectedIssue`, `JogDirection`, `StreamingMode`, `RefreshCause`, `OverrideAction`, `PointF`, `CoreError`; `translate_enum_key(&v)` → `"MacStatusIdle"` (look up `tr("Strings.<key>")`, fallback to variant name).
* `com`: `WrapperType` (UsbSerial, UsbSerial2, Telnet, LaserWebESP8266, Emulator, RJCPSerial), `ComConfig::{Serial{port_name, baud_rate}, Address(String), None}`, `list_serial_ports()`.
* `emulator`: `add_emulator_message_handler(Arc<dyn Fn(Option<&str>)>)`, `clear_emulator_message_handlers`, `trait EmulatorUiHost {show_ui, hide_ui}` + `set_ui_host`, `WebSocketEmulator::start(port)/stop()/running()`, `Grblv11Emulator::config()`.
* `laser_life`: `on_connect() -> OnConnectResult::{Selected(Option<guid>), NeedSelection(Vec<LaserLifeCounter>)}`, `select(Option<&str>)`, `on_disconnect`, `get_list_clone`, `get_current_time`, `add/edit/delete/death/undeath`, `save_now`.
* `usage_stats::{UsageCounters, load_file, save_file}`, `sincro_start::{start_listen(core, on_run), stop_listen, signal}`.

## `lg_services` (crates/services)
* `image_processor::ImageProcessor` (raster dialog driver), `autotrace`, `project` (`add_settings`, `clear_settings`, `load_project(path) -> Vec<SettingsDict>`, `store_settings(path)`, `save_image(b64, path)`), `hotkeys::{HotKeysManager, Actions, HotKey, HotKeyEffect, HotKeyContext, keys}` (`manage_hotkeys(keys_i32, ctx) -> HotKeyOutcome{handled, effects}`; key codes = WinForms `Keys`; `keys::to_egui_name/from_name`; egui has no numpad keys → use winit key names), `custom_button::{CustomButtons, CustomButton, ButtonContext{is_connected,status_idle,status_run,has_program}, ButtonTypes, EnableStyles}` (`import_plan`/`apply_import`, `export_zbn`), `layer_presets::{PresetDb, LayerPreset}`, `flash_grbl::{list_firmwares, avrdude_args, run_avrdude, BAUD_RATES, ...}`, `wifi_discovery::{scan_ip, ScanResult, DiscoveryProtocol, default_port, ...}`, `github` (update check disabled).

## `lg_gcode` (crates/gcode)
* `GrblFile` (+ `spawn_load`, `load_*`, `generate_*`, `save_gcode`, `count`, `estimated_time`, `range`, `draw_on_graphics`), `GrblCommand`, `GrblMessage`, `GrblRow` (`get_decoded_message`, `get_result`, `get_tool_tip`, `left_color`/`right_color` → `RowColor`, `image_index`), `config::{configuration(), set_configuration(), GrblConfST, GrblConfParam, GrblVersionInfo, Firmware, GPoint}`, csvd lookups.

* `settings::{get, set, exists, delete, exiting, ...}`, `paths`, `logger`, `tools::{utils::{time_span_to_string, open_link, TimePrecision}, ...}`, `sound::play_sound(EventId)`, `nrbf`.
